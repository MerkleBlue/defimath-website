<h2>Precision</h2>
<p>Error bounds were tightened alongside the speedups, and every math primitive now
carries an explicit, enforced bound (asserted in CI against the JS / decimal.js
references over full-domain sweeps):</p>
<ul>
<li><a href="/docs/math/exp/"><code>exp</code></a> — <code>2.2e-14</code> rel / <code>3.0e-16</code> abs</li>
<li><a href="/docs/math/expm1/"><code>expm1</code></a> — <code>2.2e-14</code> rel / <code>5.0e-16</code> abs</li>
<li><a href="/docs/math/pow/"><code>pow</code></a> — <code>1.0e-12</code> rel, plus a <strong>new absolute bound of <code>1.0e-14</code></strong> (previously relative-only)</li>
<li><a href="/docs/math/cbrt/"><code>cbrt</code></a> — <code>1.0e-16</code> abs</li>
<li><a href="/docs/math/erf/"><code>erf</code></a> — <code>2.0e-15</code> abs</li>
<li><a href="/docs/math/stdnormcdf/"><code>stdNormCDF</code></a> — <code>3.0e-15</code> abs</li>
</ul>
<h2>Testing &#x26; benchmarks</h2>
<p>Error tolerances and gas benchmarks now live in a single source of truth —
<code>Constants.mjs</code>, holding the <code>MAX_*_ERROR_*</code> and <code>AVG_GAS_*</code> constants — so every
published figure is asserted in CI. Gas is pinned to exact values (a test fails
on both regression <strong>and</strong> improvement, so any change surfaces in the PR diff);
behaviour tests sweep each function's full valid domain, and gas is measured over
1,000-sample sweeps balanced across the relative- and absolute-error regimes. The
Hardhat suite grew from 623 to <strong>640 tests</strong>; the Foundry property layer is
unchanged at 92 properties × 32,000 runs (2.94M executions per CI run).</p>
<h2>Behavior change</h2>
<p><code>exp</code>'s upper bound is now a round <code>135e18</code> (previously <code>135.305999…e18</code>) and
typed <code>int256</code>. Inputs in the narrow <code>(135e18, 135.306e18]</code> window that used to
succeed now revert with <code>ExpUpperBoundError</code>. Since <code>e^135</code> is already ~4×10⁵⁸,
this is far beyond any realistic financial exponent and affects no practical
caller. There are no other API changes — v3.7.0 is a drop-in upgrade.</p>
